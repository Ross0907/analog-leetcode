Analog circuit design practice

AnaCode

A schematic-first learning platform for building, simulating, measuring, and verifying analog circuits.

Open full application Source on GitHub

What it does

Schematic editor

Orthogonal wiring, automatic junctions, component placement, labels, probes, undo/redo, project import/export, and circuit-aware interaction.

Browser simulation

ngspice-WASM simulation through a Web Worker with operating-point, AC, transient, and DC-sweep workflows.

Instrumentation

Oscilloscope, curve-tracer, and Bode magnitude/phase views with multiple channels, cursors, triggering, and measurements.

Structured circuit model

Versioned validated circuit documents are normalized into an electrical IR before SPICE generation or grading.

Server-side grading

Selected challenges revalidate topology and stimulus on the server instead of trusting browser-generated answers.

Cloudflare runtime

The complete application runs on Cloudflare Workers with D1 persistence and a rate-limited grading API.

Architecture

visual schematic → validated CircuitDocument → CircuitIR → generated SPICE deck → browser ngspice-WASM → instruments validated CircuitDocument → grading API → topology/stimulus verification → engineering checks → D1 persistence
