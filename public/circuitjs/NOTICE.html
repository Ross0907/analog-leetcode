CircuitJS1 in AnaCode

The schematic editor, electrical connectivity, component symbols, native instruments and live numerical solver are provided by CircuitJS1, originally by Paul Falstad and adapted for browsers by Iain Sharp, with contributions from the upstream community.

The integration patch exposes existing native terminal positions, native node identity, native hit testing, element serialization and viewport projection through the JavaScript API. It also removes a redundant post-drag undo checkpoint so one native Undo reverses one edit. It delegates component placement and zoom to existing native commands. Its presentation hook draws supported components using official KiCad SVG symbols while retaining native terminal identity, hit testing and value labels. It does not replace the editor, routing, connectivity or solver. The host HTML sets a page title and removes upstream service-worker registration and a hardcoded manifest path. All challenge circuits are normal CircuitJS documents.
