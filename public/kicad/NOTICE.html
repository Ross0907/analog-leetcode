OPEN-SOURCE ARTWORK · KICAD COMMUNITY

KiCad symbols in AnaCode

The 21 symbols below come from KiCad's official library. KiCad's own exporter produced the artwork used in the circuit editor.

Source and license

Credit belongs to the KiCad community and KiCad Libraries. This collection uses library release 9.0.9, revision ad36cd14bcd1b1cd0484f629ccdd3481366f74f3.

The artwork and redistributed library sources retain the Creative Commons CC-BY-SA 4.0 license with the KiCad library exception. AnaCode's application license does not replace that license. The upstream license includes the original attribution and warranty terms.

The display exports hide reference/value fields and non-semantic pin labels, so the editor can show each circuit's actual labels. The op-amp's + and − markings are preserved. A temporary origin marker is removed after export, and export timestamps are normalized. All original symbol geometry is rendered by KiCad 9.0.9.

Artwork is separate from the simulation model. The three-terminal op-amp uses the graphic from Amplifier_Operational:LM2904, unit 1. This does not claim that the simulated amplifier is an LM2904 device model. CircuitJS continues to calculate the circuit using its existing models. The five-terminal SPICE op-amp is a separate artwork asset.
